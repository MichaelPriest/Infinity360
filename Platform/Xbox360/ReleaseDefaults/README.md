# Defaults of a fresh isolated alpha installation

The release ZIP includes Top Icons (J=1) and automatic library grid (G=0). Copy to a new folder; keep your original profile if desired. Classic and the other nine styles remain selectable. These markers enable personal workspace writes, HTTPS Store, XEX/ZIP app installer, XboxUnity, explicit XEX launching, continuous menu sessions and DVD-to-personal-workspace conversion. No background downloads, automatic game launch, network listeners or overwrite of boot dashboard. Existing confirmations, SHA-256 and host checks remain. Delete an individual marker and restart to disable it. XSDK physical package mounting, content installation to active Content, power/SMC, SMB authentication, FTP and upload, dashboard replacement and FFmpeg variant remain explicit experiments or separately configured. Do not add unknown credentials or change boot config. The candidate updater is deliberately minimal and does not overwrite user profiles or opt-ins. Console and Xenia hardware tests remain necessary.

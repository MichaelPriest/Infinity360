# Pastas de jogos — V0.3.78

Abra Configurações > Biblioteca > Pastas de varredura (ou Sistema > Console > opção de caminhos). A tela mantém as configurações anteriores e separa XEX de GOD/XBLA.

| Ação | Controle |
|---|---|
| Alternar XEX / pacotes | LB / RB |
| Abrir seletor de pastas | A |
| Trocar HDD/USB/unidade no seletor | LB / RB |
| Navegar em subpasta | A |
| Cadastrar pasta atual | X |
| Voltar para pasta anterior | B |
| Ativar/desativar raiz cadastrada | X na lista |
| Ajustar profundidade XEX | esquerda/direita |
| Remover cadastro criado pela interface | START, depois A |
| Atualizar biblioteca | Y |

Exemplos: hdd:/Games, usb0:/Xbox 360, usb1:/Jogos. Para GOD/XBLA selecione uma raiz contendo TitleID/Tipo, por exemplo hdd:/Content/0000000000000000. Pacotes importados mantêm sua busca própria. A profundidade 0 encontra apenas default.xex na própria pasta, 1 inclui subpastas diretas, 16 é o limite anterior. O scanner deduplica executáveis encontrados por caminhos sobrepostos; desativar uma raiz não exclui os mesmos jogos encontrados por outra raiz ativa. A indicação Acessível significa que a pasta está disponível para navegação no momento da consulta, não que contém jogos válidos. Raízes padrão ou vindas de outros arquivos podem ser desativadas, não removidas pela interface. A lista é limitada a 32 caminhos por tipo; o seletor não cadastra a unidade inteira. Não apaga, move nem renomeia jogos. Y atualiza a biblioteca explicitamente; edição também passa a valer nas próximas varreduras. Não confirma compatibilidade do conteúdo nem homologação física.

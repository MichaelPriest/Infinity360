# Fontes externas (somente autorizadas)

Este modulo recebe arquivos M3U do proprio usuario e permite exportar uma conta
Xtream autorizada para uma playlist local. Nao inclui servidores, senhas ou playlists
de canais comerciais. O repositorio da comunidade Ramys/Iptv-Brasil-2026 pode ser
consultado como exemplo de organizacao M3U, mas suas fontes nao sao homologadas
quanto a licencas, codecs ou disponibilidade.

Para listas maiores que 1500 itens, prepare um catalogo menor antes de copiar para
o Xbox 360; nao tente carregar dezenas de megabytes inteiramente na RAM.
